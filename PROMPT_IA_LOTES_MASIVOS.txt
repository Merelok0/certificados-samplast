INSTRUCTIVO — SAMPLAST / TRANSCRIPCIÓN MASIVA DESDE WHATSAPP
=============================================================

La versión principal y vigente del instructivo está integrada en la página SAMPLAST, en la sección:

INSTRUCTIVO PARA TRANSCRIPCIÓN CON IA

Use siempre esa versión porque se actualiza automáticamente con la lista actual de clientes.

FORMATO DE SALIDA VIGENTE
-------------------------
La IA debe devolver únicamente JSON válido y debe conservar el TIPO REAL de cada etiqueta:

[
  {
    "cliente": "NOMBRE DEL CLIENTE",
    "tipo": "MANUAL",
    "color": "",
    "codigo": "2012C030TD",
    "lote": "080926/R1-1DC"
  }
]

Valores admitidos para tipo:
- MANUAL
- AUTOMATICO
- PRE-ESTIRADO
- MANUAL_COLOR
- REVISAR, si la categoría no puede determinarse con seguridad

REGLA CRÍTICA
--------------
NO asumir MANUAL para todas las etiquetas.

- STFM / STMF sin otra categoría -> MANUAL
- Si la etiqueta dice AUTOMATICO / AUTOMÁTICO -> AUTOMATICO
- Si dice PRE-ESTIRADO / PRE ESTIRADO / PREESTIRADO -> PRE-ESTIRADO
- Si corresponde a film manual de color -> MANUAL_COLOR y completar color
- Si no puede determinarse el tipo -> REVISAR

Un mismo cliente puede tener etiquetas de tipos diferentes en la misma captura.

EJEMPLO MIXTO
-------------
[
  {"cliente":"INDUSTRIAS DEL PAPEL S.A.","tipo":"MANUAL","color":"","codigo":"2012C030TD","lote":"080926/R1-1DC"},
  {"cliente":"BIIPLAST","tipo":"AUTOMATICO","color":"","codigo":"2014C0160TG","lote":"270626/E4-2RQ"},
  {"cliente":"BIIPLAST","tipo":"MANUAL","color":"","codigo":"2012C014TD","lote":"080926/R1-2IS"}
]

La página SAMPLAST calcula automáticamente características del producto y fechas a partir del código y lote cuando el patrón está reconocido.
