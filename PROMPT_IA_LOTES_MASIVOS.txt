INSTRUCTIVO — SAMPLAST / TRANSCRIPCIÓN MASIVA DESDE WHATSAPP
=============================================================

La versión principal y vigente del instructivo está integrada en la página SAMPLAST, en la sección:

INSTRUCTIVO PARA TRANSCRIPCIÓN CON IA

Use siempre esa versión porque se actualiza automáticamente con la lista actual de clientes.

REGLAS IMPORTANTES
------------------
1. Devuelva únicamente JSON válido.
2. Debe existir un objeto por cada etiqueta física.
3. No asumir MANUAL para todas las etiquetas.
4. STFM / STMF / STF MANUAL -> MANUAL.
5. AUTOMATICO / AUTOMÁTICO -> AUTOMATICO.
6. PRE-ESTIRADO -> PRE-ESTIRADO.
7. STF NEGRO / ROJO / AZUL / VERDE / AMARILLO -> MANUAL_COLOR y completar color.

CODIGO TECNICO VS CODIGO SAP
-----------------------------
Los códigos técnicos SAMPLAST como 2012C030TD, 1812C029TD o 2014C0160TG sí se colocan en "codigo".

Los códigos SAP como P00447, P00651, etc. NO se usan para generar el certificado.
Si la etiqueta trae CODIGO SAP y además imprime directamente las medidas, ignore el SAP, deje "codigo" vacío y coloque las medidas en "formato".

Ejemplo ANTALIS:
Etiqueta: STF MANUAL 06", 06" x 20 x 0.60 KG, CODIGO SAP P00447, LT:140926/R6-1JC
Salida:
{"cliente":"ANTALIS TFM S.A.","tipo":"MANUAL","color":"","codigo":"","formato":"06*20*0.60","lote":"140926/R6-1JC"}

Etiqueta: STF NEGRO 09", 09" x 20 x 1.00 KG, CODIGO SAP P00651, LT:140926/R6-1JC
Salida:
{"cliente":"ANTALIS TFM S.A.","tipo":"MANUAL_COLOR","color":"NEGRO","codigo":"","formato":"09*20*1.00","lote":"140926/R6-1JC"}

PRE-ESTIRADO
-------------
Puede no tener código técnico. Lea las medidas impresas y colóquelas en "formato".
Ejemplo: 18" X 09 MC X 2.50 KG -> "formato":"18*09*2.50" y "codigo":"".

FORMATO GENERAL
---------------
[
  {
    "cliente": "NOMBRE DEL CLIENTE",
    "tipo": "MANUAL",
    "color": "",
    "codigo": "2012C030TD",
    "formato": "",
    "lote": "080926/R1-1DC"
  }
]

La página calcula automáticamente las fechas desde los primeros seis dígitos del lote (DDMMAA).
